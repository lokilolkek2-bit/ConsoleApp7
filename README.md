# ConsoleApp7ServerTCP1 — асинхронный TCP-сервер

Проект переведён на конкурентную обработку TCP-клиентов с использованием `async`/`await`.

## Требования

- .NET 8 SDK
- Windows, Linux или macOS

## Запуск

Из каталога `ConsoleApp7` выполните:

```bash
dotnet run
```

Сервер слушает TCP-порт `5000`. Для остановки нажмите `Ctrl+C`.

## Протокол

- Обычный текст — сервер возвращает его в верхнем регистре.
- `PING example.com` — сервер выполняет HTTP-запрос и возвращает время ответа и HTTP-статус.

Для проверки откройте два отдельных TCP-клиента и подключитесь к `127.0.0.1:5000`.

Например, в Windows PowerShell можно использовать два отдельных окна:

```powershell
$client = [System.Net.Sockets.TcpClient]::new('127.0.0.1', 5000)
$stream = $client.GetStream()
$writer = [System.IO.StreamWriter]::new($stream)
$writer.AutoFlush = $true
$writer.WriteLine('hello')
$buffer = [byte[]]::new(1024)
$count = $stream.Read($buffer, 0, $buffer.Length)
[System.Text.Encoding]::UTF8.GetString($buffer, 0, $count)
```

> Сервер сохраняет исходный протокол без разделителя строк в ответе. Поэтому ответ считывается как набор байтов, а не методом `ReadLine()`.

## Что изменено

- Приём новых подключений выполняется через `AcceptTcpClientAsync`.
- Для каждого клиента запускается отдельная задача `HandleClientAsync`; ожидание одного клиента больше не останавливает приём остальных.
- Чтение и отправка данных выполняются асинхронно через `ReadAsync` и `WriteAsync`.
- Возврат `0` из `ReadAsync` распознаётся как штатное отключение клиента.
- Ошибки `IOException`, `SocketException` и отмена операций обрабатываются отдельно; ресурсы клиента освобождаются в `finally`.
- При `Ctrl+C` сервер прекращает приём подключений, закрывает активные сокеты и ожидает завершения задач клиентов.
- Сохранена исходная логика: обычные сообщения преобразуются в верхний регистр, команда `PING` проверяет доступность URL.

## Проверка

1. Запустить сервер.
2. Подключить два клиента к `127.0.0.1:5000`.
3. Отправить сообщения от обоих клиентов и убедиться, что ответы приходят независимо.
4. Закрыть соединение одного клиента.
5. Убедиться, что сервер продолжает обслуживать второго клиента.
6. Остановить сервер сочетанием `Ctrl+C`.

Фактические скриншоты тестирования следует сделать после запуска проекта в своей среде.
